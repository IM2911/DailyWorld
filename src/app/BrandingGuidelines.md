# DailyWorld Premium Brand Guidelines

## Brand Identity

### Colors
- **Primary**: #2563eb (Blue)
- **Primary Dark**: #1e40af (Dark Blue)
- **Primary Light**: #dbeafe (Light Blue)
- **Primary Muted**: #eff6ff (Very Light Blue)
- **Secondary**: #0f172a (Slate)
- **Secondary Light**: #1e293b (Dark Slate)
- **Success**: #10b981 (Green)
- **Warning**: #f59e0b (Orange)
- **Error**: #ef4444 (Red)

### Typography
- **Headings**: SF Pro Display, Inter, system-ui
- **Body**: Inter, system-ui
- **Size Scale**: 16px base, with clear hierarchy for h1-h3

### Visual Elements
- **Border Radius**: 8px - 16px consistent across components
- **Shadows**: Subtle, professional shadows with depth
- **Spacing**: 4px - 48px scale
- **Animations**: Smooth transitions, 150-400ms durations

## Component Standards

### Buttons
- Primary: Brand background, white text, rounded corners
- Secondary: Transparent background, brand border
- Hover states: Subtle lift and shadow enhancement

### Cards
- Background: White surface with subtle border
- Hover: Lift effect, brand border, enhanced shadow
- Padding: 24px - 48px
- Border radius: 12px - 16px

### Navigation
- Spacing: Consistent with body text
- Active states: Brand color, underline effect
- Hover states: Background subtle highlight

### Forms
- Inputs: Clean borders, subtle focus states
- Validation: Visual feedback, color coding

## Design Principles

1. **Minimalist**: Maximum space, clean aesthetics
2. **Hierarchy**: Clear visual ranking of elements
3. **Consistency**: Uniform patterns across all pages
4. **Accessibility**: WCAG compliance, keyboard navigation
5. **Performance**: Optimized loading, smooth animations

## Content Guidelines

- Use professional, technical language
- Maintain clear value propositions
- Present data accurately and visually
- Provide comprehensive, well-structured content

## Visual Hierarchy

1. **H1**: 3rem - 4.5rem, bold, tracking -2%
2. **H2**: 2rem - 3rem, bold, tracking -1%
3. **H3**: 1.5rem - 2rem, semibold
4. **Body**: 1rem - 1.125rem, line-height 1.6

## Layout Principles

- **Grid System**: 12-column responsive grid
- **Containers**: 1200px max-width
- **Side Margins**: 16px - 24px
- **Section Spacing**: 48px - 96px

## Interaction Patterns

- **Hover**: Scale 1.02, shadow enhancement
- **Active**: Scale 0.98
- **Focus**: Ring outline, high contrast
- **Transition**: All transitions 150-400ms

## Animation Guidelines

- **Entrance**: Slide-up with delay stacking
- **Hover**: Subtle lift and scale
- **Scroll**: Reveal animations
- **Reduced Motion**: Respect user preferences

## Visual Elements

- **Icons**: Consistent weight, sizing
- **Images**: Purposeful, professional
- **Backgrounds**: Subtle gradients, textures
- **Overlays**: Translucent, non-intrusive
